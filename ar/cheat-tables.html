كمّل بالإنجليزي

جداول المراجعة

صفحة لكل مجال فيها أهم النقط، والحاجات اللي تبعد عنها، وتفاصيل الإعدادات، وجداول المقارنة. استخدمها في المراجعة الأخيرة، وكل صفحة بتتطبع كويس من المتصفح.

المجال 1

معمارية الوكلاء والتنسيق بينهم

  1. 1.1تصميم وتنفيذ حلقات الوكيل عشان الوكيل ينفّذ المهام لوحده
  2. 1.2تنسيق الأنظمة متعددة الوكلاء بأنماط المنسّق والوكلاء الفرعيين
  3. 1.3ظبط استدعاء الوكلاء الفرعيين، وتمرير السياق ليهم، وإطلاقهم
  4. 1.4تنفيذ سير عمل متعدد الخطوات بأنماط للفرض الإجباري وللتسليم
  5. 1.5استخدام هوكات Agent SDK عشان تعترض استدعاءات الأدوات وتوحّد شكل البيانات
  6. 1.6تصميم استراتيجيات لتقسيم المهام في سير العمل المعقّد
  7. 1.7إدارة حالة الجلسة، واستئنافها، والتفرّع منها
المجال 2

تصميم الأدوات وربط MCP

  1. 2.1تصميم واجهات أدوات فعّالة، بأوصاف واضحة وحدود محددة لكل أداة
  2. 2.2تطبيق ردود أخطاء منظّمة لأدوات MCP
  3. 2.3توزيع الأدوات على الوكلاء بشكل مناسب وضبط إعداد اختيار الأداة
  4. 2.4دمج سيرفرات MCP في Claude Code وفي سير عمل الوكلاء
  5. 2.5اختيار الأدوات المدمجة (Read، Write، Edit، Bash، Grep، Glob) واستخدامها صح
المجال 3

إعدادات Claude Code وطريقة الشغل بيه

  1. 3.1اظبط ملفات CLAUDE.md بتسلسل مستويات مناسب ونطاق صح، وقسّمها لأجزاء منظمة
  2. 3.2اعمل أوامر سلاش ومهارات مخصصة واظبط إعداداتها
  3. 3.3طبّق قواعد مربوطة بمسارات معينة عشان المعايير تتحمّل بس وقت ما تلزم
  4. 3.4حدد إمتى تستخدم وضع التخطيط وإمتى تنفّذ على طول
  5. 3.5استخدم أساليب التحسين على مراحل عشان تحسّن النتيجة خطوة بخطوة
  6. 3.6ادمج Claude Code في خطوط CI/CD
المجال 4

هندسة البرومبت والمخرجات المنظّمة

  1. 4.1إزاي تصمم برومبتات فيها معايير صريحة عشان تحسّن الدقة وتقلل الإنذارات الكاذبة
  2. 4.2استخدم الأمثلة التوضيحية عشان تحسّن ثبات المخرجات وجودتها
  3. 4.3إزاي تفرض مخرجات منظّمة باستخدام الأدوات ومخططات JSON
  4. 4.4إزاي تبني التحقق وإعادة المحاولة وحلقات التغذية الراجعة عشان جودة استخراج البيانات
  5. 4.5إزاي تصمم استراتيجيات كفء للمعالجة بالدفعات
  6. 4.6إزاي تصمم طرق مراجعة بأكتر من نسخة وعلى أكتر من جولة
المجال 5

إدارة السياق والاعتمادية

  1. 5.1إزاي تدير سياق المحادثة عشان المعلومات المهمة متضيعش في التفاعلات الطويلة
  2. 5.2تصميم طرق فعّالة للتصعيد وحل الغموض
  3. 5.3تطبيق طرق لتمرير الأخطاء بين الوكلاء في الأنظمة متعددة الوكلاء
  4. 5.4إدارة السياق بكفاءة وإنت بتستكشف قاعدة كود كبيرة
  5. 5.5تصميم سير عمل للمراجعة البشرية ومعايرة درجة الثقة
  6. 5.6الحفاظ على مصدر المعلومة والتعامل مع عدم اليقين لما تجمّع معلومات من كذا مصدر
